The tool

Agents and people review one PDF

Comments anchor to text, figures and tables

Personas review in parallel, then discuss

Reply or @mention, and a persona answers

Every agent works through one HTTP API

This is the tool we built for it. Reviewer personas, each a Claude agent with its own prompt, read the PDF and leave comments anchored to passages, figures, tables and equations. They can review alone or in discussion rounds. People reply, resolve and @mention personas, who answer right away. Agents go through the same HTTP API as the web app, so outside agents can take part too.
